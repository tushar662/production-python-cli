# Production Python CLI Task Manager

## 1. Project Goal

Build a production-style command-line Task Manager using Python.

The application will allow users to create, view, update, and delete tasks from the command line.

## 2. Core Features

- Add a new task
- List all tasks
- Mark a task as completed
- Delete a task

## 3. Task Information

Each task will contain:

- ID
- Title
- Completed status
- Created timestamp

## 4. Technology Stack

- Python
- Object-Oriented Programming (OOP)
- Type Hints
- SQLite
- argparse
- Logging
- Exception Handling
- Pytest
- Git
- GitHub
