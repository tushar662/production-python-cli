# Project Rules

1. Follow the project’s day-wise learning roadmap and keep work aligned with its current stage.
2. Explain every new Python concept in clear, beginner-friendly language.
3. Write clean, maintainable, production-quality code.
4. Use type hints and object-oriented design where they are appropriate.
5. Add pytest tests for new functionality.
6. Run the relevant test suite before committing changes.
7. Never push changes when tests fail.
8. Never expose API keys, credentials, tokens, or other secrets in source code, logs, documentation, or command output.
9. Never force-push.
10. After completing a successful milestone and confirming its tests pass, commit the milestone and push it to `origin/main` automatically.
11. Explain each commit and summarize the changes it contains.
12. Maintain a project progress log that records completed milestones, current progress, and next steps.
